# A牌對決完整產品規劃

## 產品定位

A牌對決是一款兩位玩家透過隱藏資訊、階級剋制與鄰牌掩護進行的短局制線上牌桌。核心體驗是快速開局、清楚判斷目前操作方，以及每次翻牌後留下可持續推理的公開資訊。

目標使用者：

- 想用網址快速邀請朋友對戰的玩家。
- 在同一台裝置測試規則的設計者。
- 想觀看進行中牌局的觀戰者。

## 核心旅程

1. 玩家以暱稱建立訪客身份，重新整理後仍維持登入。
2. 玩家建立公開對局，取得六碼代碼與邀請連結。
3. 第二位玩家從清單或代碼加入；滿員後其他人以觀戰者加入。
4. 攻方選牌與目標，守方選擇直面或存活的左右鄰牌掩護，攻方確認結算。
5. 戰鬥中存活且翻開的牌持續公開；退場牌不再參與鄰牌計算。
6. 其中一方無存活牌或投降時結束，雙方可開始下一局。

## V1 已交付範圍

### 登入模組

- 暱稱訪客登入與 30 天工作階段。
- 瀏覽器登入恢復、登出與失效處理。
- 伺服器重新啟動後仍可恢復身份。

### 對局管理模組

- 建立六碼對局、公開清單、代碼加入與滿房觀戰。
- 等待中、對戰中、已結束三種生命週期。
- 玩家在線狀態、返回大廳、進行中離開判定投降。
- 等待房六小時、非活躍對局七天後自動清理。
- 牌局狀態寫入本機 JSON 資料檔。

### 連線模組

- WebSocket 即時同步與伺服器權威狀態。
- 指數退避自動重連、心跳與異常連線清理。
- 訊息大小與頻率限制。
- 攻方、守方、觀戰者及操作階段權限驗證。
- 對不同觀看者遮蔽未揭露牌的名稱、類型與階級。

### 遊戲與介面

- 公爵至騎士、炸藥、陷阱與騎士剋公爵規則。
- 死亡牌跳過後，以最近存活的左右牌作為掩護候選。
- 參與 VS 且存活的牌維持揭露狀態。
- 線上大廳、本機對戰、正式牌桌、戰況與勝負畫面。
- 桌面、平板與手機橫向卡牌列版面。

## 系統邊界

```text
React UI
  |-- HTTP: 登入、房間清單、建立／加入／退出
  |-- WebSocket: 動作送出、個人化牌局狀態、重連
  v
Node.js Server
  |-- Session 管理
  |-- Match 生命週期
  |-- Action 權限與 Battle Engine
  |-- 未揭露資料遮蔽
  v
data/a-duel.json
```

遊戲規則維持純函式，伺服器負責判斷誰能在何時呼叫規則；前端只負責呈現與送出意圖。瀏覽器收到的敵方隱藏牌已遮蔽，不能透過開發者工具讀取真實內容。

## 品質門檻

- 每次交付必須通過 `npm run check`。
- 核心規則、鄰牌跳過、揭露狀態與線上角色權限需有自動測試。
- 正式環境只從同源載入資源，並限制 iframe、來源與內容類型。
- 任何網路中斷不得清空伺服器牌局；重連後以伺服器狀態覆蓋前端。

## 後續版本

### V1.1

- 雙方同意後再重賽，顯示重賽等待狀態。
- 私人房、房主踢除觀戰者與房間密碼。
- 玩家自訂牌序的開局準備階段。
- 安裝式 PWA 與斷線提示強化。

### V2

- 正式帳號、密碼重設與第三方登入。
- PostgreSQL 資料庫、跨程序工作階段與多台伺服器擴充。
- 快速配對、積分、戰績、好友與邀請通知。
- 對局回放與裁判稽核紀錄。

### V3

- 賽季、排行榜、私人賽事與管理後台。
- 多語系、無障礙完整稽核與原生行動裝置封裝。

## 目前限制

V1 採訪客身份與單機 JSON 儲存，適合單台主機的小型公開測試。若要正式商業營運，需先完成 V2 的帳號安全、資料庫、備份、監控、TLS 與橫向擴充。
